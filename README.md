# МДО: демо взыскания задолженности

Интерактивный прототип модуля взысканий. Владелец: Leonid Netizen.

Сайт: https://leonidsaidulin-netizen.github.io/mdo-demo-vzyskanie/

Только синтетические данные. Нет подключения к рабочему биллингу, отправки
сообщений жителям, подачи документов в суд или реальных платежей.
Действия сохраняются локально в браузере посетителя и не синхронизируются между
пользователями. Не загружайте в публичный прототип персональные данные.

## Разработка

Исходные модули находятся в `dist/*.mjs`; `build.mjs` создаёт версионированный
браузерный bundle. Шрифты и библиотеки включены в поставку, внешние CDN не нужны.

```sh
npm ci
npm test
npm run build
npm start
```

Локальный адрес: http://127.0.0.1:8784/

Публикация: push в `main` запускает тесты, сборку и GitHub Pages.
При ошибке тестов новая версия не публикуется.

## Подтверждение действий

Открытие окна уведомления, выбор каналов и просмотр текста работают только
с временной копией данных. Дело, документы и события сохраняются вместе после
явного подтверждения. Отмена не меняет задолженность, стадию и историю.
Несколько каналов создают одно дело; повторное подтверждение не создаёт дубль.
Если данные изменились после предпросмотра, подтверждение блокируется.

Проверки отмены форм на всех стадиях: `tests/confirmation-boundary.test.mjs`.
Полные пути соглашения, приказа, иска, банка/ФССП и завершения:
`tests/full-journey.test.mjs`. Внешние отправки остаются отключёнными.
